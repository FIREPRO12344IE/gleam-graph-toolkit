# TS Workshop Website Plan

## Goal
Build a polished one-page motorcycle workshop website that follows the supplied brief: dark, mechanical, bold, fast, and credible, with restrained yellow, red, and blue accents.

## Visual direction
- Create an editorial motorsport look with sharp geometry, strong condensed headings, dark charcoal surfaces, and generous spacing.
- Generate one cinematic, photorealistic workshop image for the opening section, composed for readable overlaid text and avoiding generic stock-photo styling.
- Keep the gallery honest with clearly designed upload placeholders for TS Workshop’s future real photographs.
- Use subtle image/text reveals and compact-on-scroll navigation, while respecting reduced-motion settings.

## Page structure
1. Sticky navigation with working section links, quote action, and a purposeful mobile menu.
2. Full-height opening section with the supplied headline, supporting line, two actions, and scroll cue.
3. Numbered services editorial layout covering all seven listed services.
4. Transparent pricing section using only the requested editable price placeholders.
5. Photography-led work gallery with one feature slot, supporting slots, full-screen viewer, and mobile swipe controls.
6. “Why TS Workshop” statement and the three supplied principles.
7. About area using clearly labelled owner-provided content placeholders only.
8. Genuine-review placeholders without fabricated names, ratings, or claims.
9. Strong quote section with every requested field; submission opens a prepared email draft using an obvious placeholder address until the real address is supplied.
10. Integrated social, contact, map placeholder, and premium footer with editable business details.

## Quality and behaviour
- Make every navigation item, CTA, menu, gallery control, and form interaction functional.
- Validate required enquiry details before creating the email draft, with clear accessible feedback.
- Tune layouts specifically for 320px, 375px, 390px, 430px, tablet, desktop, and large desktop widths.
- Add semantic structure, keyboard support, visible focus states, strong contrast, optimized imagery, and route-specific search/social metadata.
- Keep unknown prices, contact details, history, qualifications, reviews, and social URL as explicit placeholders rather than invented content.

## Technical approach
- Build within the existing TanStack Start and Tailwind v4 foundation, using reusable focused sections and semantic design tokens.
- Keep the site frontend-only and static-host compatible; the email-draft enquiry flow requires no database, server, secrets, or proprietary runtime.
- Verify the production build, existing routing tests, mobile/desktop rendering, navigation, gallery viewer, mobile menu, and enquiry flow before completion.
